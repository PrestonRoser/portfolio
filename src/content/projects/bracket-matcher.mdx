Completed an instructor-provided C++ skeleton into a bracket validator.

- Walks the input with a stack, pushing opening brackets and matching each closing bracket against
  the top of the stack.
- Reads a custom set of bracket pairs from the first line of the file, so the checker is not tied
  to one language's syntax.
- Takes input from a file or from standard input.
