A tree data structure built from scratch, then put to work on tic-tac-toe.

- A generic `ArrayTree` stores an order-n tree in a flat array, finding parents and children by
  index arithmetic instead of node references.
- From an empty board, the generator recursively expands every legal move, alternating players
  until the board fills.
- A separate harness checks the tree operations against expected values.
