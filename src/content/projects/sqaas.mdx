A full-stack user story application built by a team over five months.

- Supports user stories, support tickets, OTP account recovery, direct messaging and threaded Q&A,
  with separate roles and role-based access.
- Developed with Git-based workflows, CI/CD pipelines, automated testing and iterative delivery.
- Persistent data management on a SQL back end.
