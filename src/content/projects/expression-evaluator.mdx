Completed an instructor-provided C++ skeleton into a working expression evaluator.

- An abstract base class declares pure virtual methods for evaluating an expression and printing
  it in infix and postfix form.
- Constant, unary, and binary subclasses build the expression tree, so one call on the root
  handles any shape of expression.
- Virtual destructors free child nodes, which is what keeps the tree from leaking as it unwinds.
